

# 🎵 Music Playlist

https://setare-heydarvand-web.github.io/mini-playlist/

A modern and interactive music playlist built with **HTML, Tailwind CSS, and JavaScript**.

This mini project was created to practice JavaScript fundamentals such as **DOM manipulation, functions, variables, conditions, and click events** while building a clean and responsive music player interface.

## ✨ Features

* 🎧 Multiple songs in one playlist
* ▶️ Play / Pause controls
* ⏭️ Next and Previous song
* 🎵 Dynamic song information
* 💿 Album artwork changes with the current song
* 📱 Fully responsive design
* ✨ Modern UI with Tailwind CSS
* ⚡ Interactive controls powered by JavaScript

## 🛠️ Built With

* **HTML5**
* **Tailwind CSS**
* **JavaScript**
* **HTML5 Audio API**

## 🎯 What I Practiced

Through this project, I practiced:

* DOM Manipulation
* `let` and `const`
* Functions
* `if / else`
* Event Listeners
* Click Events
* Arrays & Objects
* Updating HTML elements dynamically
* Working with the HTML Audio API

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/setare-heydarvand-web/music-playlist.git
```

Open the project folder:

```bash
cd music-playlist
```

Then open `index.html` in your browser.

## 💡 About The Project

The goal of this project was to build a small but practical JavaScript application instead of creating another simple button-click exercise.

The playlist allows users to interact with multiple tracks and dynamically update the player based on the selected song.
